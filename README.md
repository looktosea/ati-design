## 已确认的产品目标

在交易日 14:30–14:50，结合大盘热度、市场状态、板块轮动、资金行为、政治政策与个股特征，从全部非 ST A 股中快速筛选不超过 5 只候选。以随后 3 个交易日的表现作为主要观察依据，1 日与 5 日辅助。系统提出筛选条件和因子调整方案，由用户确认后启用；交易完全手动。

API 已由用户提供 Fuyao（同花顺金融数据 API），本版先完成只读能力核验和供应商映射；密钥不写入仓库或文档，运行时通过环境变量注入。使用已有 VPS，不讨论其采购及费用。本版不拆分开发任务。

## 如何理解文档中的决定

- **已确认**：来自用户明确要求，见整体框架第 1 节。
- **设计建议**：为了使方案可评审而给出的具体做法，不代表已经获得策略效果验证。
- **研究初值**：窗口长度、分位数、阈值、组合方式等候选参数；必须版本化，经验证并确认后才可启用。
- **待 API 核验**：字段覆盖、实时性、历史深度与数据语义。缺少这些能力时不能宣称对应因子已实现。

40 个因子构成研究目录，不代表首版同时评分或同时优化 40 个参数。基础组合、增强组合、解释标签和安全门控分开管理。

开发前模板仅用于查看非敏感配置。真实 API Key 必须由进程环境变量 `FUYAO_API_KEY` 注入后再运行 `python3 scripts/check_data_sources.py`；不要把密钥写入 `.env` 或任何配置文件。需要检查东方财富影子源时再加 `--shadow`。脚本不会打印密钥，也不会写入行情数据。

## 本次相对原始讨论稿的主要调整

- 从盘后日线选股调整为历史日线与尾盘时点数据结合。
- 将市场环境、机会排序、风险门控分离，避免共同市场分数重复加到每只股票。
- 明确资金流统计与量价代理指标的区别，明确政策事实与影响推断的区别。
- 因子全部遵守当时可知原则；历史成分、交易状态、政策版本与计算口径可追溯。
- 将自动模拟交易、券商执行、账户仓位管理移出核心范围；采用独立的信号参考评价。
- 将 HMM、大模型预测、自动调权改为可比较的研究方案，不作为前置依赖。
- 补全数据缺失、候选为空、无法估计成交、停牌及评价缺失的处理规则。

## 重要边界

本版没有宣称任何因子具有正向预测能力，也没有给出已验证的胜率或收益目标。胜率、参考收益及不利波动均为信号研究指标，不等同于实际账户盈亏。

具体外部资料及用途见[数据契约与验证规则第 11 节](docs/03-data-and-validation.md#11-外部资料与使用边界)。资料用于核验交易和数据限制，不作为所设计因子有效性的证明。

## 首轮工程运行

安装后可先执行离线迁移：

```bash
python3 -m ati migrate
```

运行基础数据闭环前，在进程环境中注入 `FUYAO_API_KEY`（不会从配置文件读取密钥）：

```bash
export FUYAO_API_KEY='…'
python3 -m ati foundation
```

`foundation` 依次保存 Fuyao 代码表、交易日历和全市场快照的原始响应，并写入 SQLite 的首轮表。原始响应存放在 `ATI_RAW_DATA_DIR`（默认 `data/raw`），数据库可用 `ATI_DATABASE_URL=sqlite:///data/ati.db` 覆盖。快照质量门控会区分空结果、重复代码、缺少标识和过期时间戳；门控失败时不会把结果标记为有效。

### L1 因子与日线初始化

```bash
# 对已保存的最新全市场快照计算 L1 因子并写入信号/评价表
python3 -m ati l1

# 日线按 Fuyao 每批最多 10 个代码导入；密钥只从环境变量读取
python3 -m ati history --codes 600000.SH,000001.SZ --start 2025-01-01 --end 2026-11-11
```

没有足够的 D-1 日线历史时，L1 会保存 `INSUFFICIENT_HISTORY` 因子结果并生成 `NO_CANDIDATE` 信号，不会用实时快照冒充趋势历史。重复运行使用相同业务键幂等写入。

### 质量、复盘和备份

```bash
python3 -m ati quality
python3 -m ati report
python3 -m ati backup --path data/backups/ati-$(date +%Y%m%dT%H%M%S).db
```

`quality` 返回 `VALID` 或 `BLOCKED`，检查快照时效、因子键重复、任务失败和核心表覆盖；`backup` 使用 SQLite 在线备份接口，不复制半写入文件。
